🧩 Aturan Malomo — PRD FINAL
Struktur 1D–4H → zona 4H → konfirmasi close 1H. EMA hanya informasi. ATR/RVOL bukan hard gate. RR minimum 1:2.2. SL keluar tanpa menunggu retest.
📨 Notifikasi Telegram
Kirim alarm (🚨) ke Telegram kamu juga, selama app aktif dan tersambung di browser. Token & Chat ID cuma disimpan lokal di browser ini (localStorage) — tidak pernah ikut ke-push ke GitHub atau server manapun.
📈 Histori Setup
Tiap kamu tap "📌 Simpan ke Histori Setup" di detail pair, Trading Plan Malomo (arah, entry, SL, TP) kesimpen di sini. Rencana yang dipantau dan selesai dicatat dengan hasil TP/SL berdasarkan level plan. Riwayat candle diperiksa setelah aplikasi kembali aktif. Hasil ini bukan fill nyata dari exchange; sesuaikan dengan eksekusi manualmu.
